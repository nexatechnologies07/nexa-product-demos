# Upload Guide

## Images
Copy approved screenshots into the matching `images` folder.

## Videos
GitHub has file-size limitations. Prefer:
1. YouTube Unlisted for long videos.
2. Google Drive public-view link for backup.
3. GitHub only for short compressed preview clips.

## Never Upload
- Full source code
- Database backups
- `.env` files
- API keys
- Buyer information
- Customer records
- Demo usernames/passwords unless created specifically for public access
